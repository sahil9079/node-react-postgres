## 2. `apiserver/` — the backend

### Entry points and configuration

| File | What it does |
| :--- | :--- |
| `index.js` | Starts the server, connects to the DB, handles shutdown signals |
| `app.js` | Builds the Express app: middleware, probes, metrics, static files, routes, errors |
| `api.js` | Mounts `/auth`, `/users`, `/skills` under `/api/v1` |
| `config/index.js` | Chooses the port and URLs based on `NODE_ENV` |
| `package.json` | Backend dependencies and test scripts |
| `package-lock.json` | Exact versions |
| `Dockerfile` | Two-stage production image, non-root, healthcheck |
| `.dockerignore` | Keeps secrets, tests and `node_modules` out of the image |
| `example.env` | Template of required environment variables |
| `.config.env` | Your real local settings. **Git-ignored. Never commit.** ⚠️ |
| `babel.config.js` | Lets Jest understand modern JavaScript |
| `jest.config.js` | Test settings and 50% coverage gate |
| `metrics.js` | Collects HTTP metrics and exposes `/metrics` |

### `routes/` — the URL list

| File | URLs |
| :--- | :--- |
| `authRoutes.js` | `POST /register`, `GET /verify/:token`, `POST /login`, `GET /check-auth`, `GET /logout` |
| `userRoutes.js` | `GET /`, `POST /` (profile + image), `PATCH /` (password) |
| `skillRoutes.js` | `GET /`, `GET /:skillId`, `POST /`, `PATCH /:skillId`, `DELETE /:skillId` |

### `controllers/` — handle request and response

| File | What it does |
| :--- | :--- |
| `authController.js` | Register, verify, login, check session, logout |
| `userController.js` | Get profile, update profile/image, change password |
| `skillController.js` | List, read, create, update, delete skills |

### `services/` — business logic

| File | What it does |
| :--- | :--- |
| `authService.js` | Password check, JWT creation, cookie creation, session check |

### `middleware/` — runs before controllers

| File | What it does |
| :--- | :--- |
| `isLoggedIn.js` | Reads the cookie, validates it, sets `req.userId` |
| `athorizeOnly.js` | Role check (filename typo; currently unused) |
| `convertErrors.js` | Turns JWT/Sequelize errors into `AppError` |
| `handleErrors.js` | Sends the error response (dev = details, prod = safe) |
| `uploadSingleFile.js` | Multer upload for one file |
| `uploadMutipleFiles.js` | Multer upload for several file fields (filename typo) |
| `resizeSingleImage.js` | Sharp resize for one image |
| `resizeMultipleImages.js` | Sharp resize for many images |

### `models/` — database description

| File | Table |
| :--- | :--- |
| `index.js` | Creates the Sequelize connection and loads models |
| `sampledb/index.js` | Defines relationships (User↔Skill, Role↔User, Skill↔LocationOption) |
| `sampledb/user.js` | `user` table + password hashing |
| `sampledb/skill.js` | `skill` table |
| `sampledb/role.js` | `role` table (`user`, `admin`, `superAdmin`) |
| `sampledb/locationOption.js` | `location_option` table (`choose`, `instructor`, `online`) |

### `utils/` — small helpers

| File | What it does |
| :--- | :--- |
| `appError.js` | Standard error object with status code |
| `catchAsync.js` | Catches async errors and passes them to Express |
| `jwt.js` | Sign, verify and decode JWT |
| `session.js` | AES encrypt/decrypt for the cookie |

| File | Tests |

## 4. `k8s/` — Kubernetes manifests

Read in this order:

| File | What it creates |
| :--- | :--- |
| `namespace.yaml` | Namespace `node-react-app` |
| `configmap.yaml` | Non-secret settings |
| `secret.yaml` | Local-only secrets ⚠️ |
| `external-secret.yaml` | AWS Secrets Manager → Kubernetes Secret (production) |
| `serviceaccount.yaml` | Pod identity for AWS |
| `rbac.yaml` | Read-only Role and RoleBinding |
| `dbpvc.yaml` | Disk for local Postgres (has a YAML indentation bug) |
| `dbdep.yaml` | Local Postgres Deployment |
| `dbsrc.yaml` | Local Postgres Service |
| `apidep.yaml` | API Deployment (2 replicas, probes, limits) |
| `apisrc.yaml` | API Services (`apiserver-service` + alias `apiserver`) |
| `clientdep.yaml` | Frontend Deployment |
| `clientsrc.yaml` | Frontend Service |
| `ingress.yaml` | ALB Ingress and path routing |
| `hpa.yaml` | Autoscaling for API and client |
| `pdb.yaml` | Disruption budgets |
| `kustomization.yaml` | Base list of resources |
| `overlays/lab/kustomization.yaml` | Lab: 1 replica, RDS endpoint, `DB_SSL=true` |
| `overlays/production/kustomization.yaml` | Production: 3 API replicas, ExternalSecret |
