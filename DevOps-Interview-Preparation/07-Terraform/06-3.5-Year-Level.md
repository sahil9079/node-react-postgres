# Terraform Fundamentals - Level 5: 3–3.5 Year Engineer Mastery

## 1. Troubleshooting Terraform State Locks
* **Incident:** `Error: Error acquiring the state lock: ConditionalCheckFailedException`. A CI/CD runner aborted mid-execution, leaving the DynamoDB lock acquired.
* **Resolution Process:**
  1. Verify no other engineer or pipeline is currently running.
  2. Inspect the Lock ID in the error output (`e.g. 5d9b62c2-842b-b684-18cb-7e2794df7e3a`).
  3. Execute targeted force unlock:
     ```bash
     terraform force-unlock 5d9b62c2-842b-b684-18cb-7e2794df7e3a
     ```
