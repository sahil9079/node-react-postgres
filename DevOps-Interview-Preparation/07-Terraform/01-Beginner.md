# Terraform Fundamentals - Level 0: Beginner

## 1. What is Terraform?
Terraform is an open-source Infrastructure as Code (IaC) tool created by HashiCorp. It allows you to define, provision, and version cloud infrastructure (AWS, Azure, GCP) using a declarative configuration language called HCL (HashiCorp Configuration Language).

## 2. Why do we need it?
* **Declarative:** You describe *what* you want the end-state to look like, and Terraform figures out *how* to build it.
* **Version Controlled:** Infrastructure definitions are stored in Git, enabling code reviews, audits, and rollbacks.
* **Repeatable & Consistent:** Eliminates manual click-ops errors in cloud consoles.
