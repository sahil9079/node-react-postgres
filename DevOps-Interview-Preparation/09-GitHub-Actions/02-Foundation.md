# GitHub Actions - Level 1: Foundation
## 1. Core Components
* **Workflow (`.github/workflows/*.yaml`):** The automated pipeline definition.
* **Events (`on: [push, pull_request]`):** Triggers that start the workflow.
* **Jobs:** Set of steps executing on the same runner environment.
* **Runners:** Machines that execute jobs (`ubuntu-latest` or self-hosted).
* **Steps / Actions:** Individual commands or reusable community actions.
