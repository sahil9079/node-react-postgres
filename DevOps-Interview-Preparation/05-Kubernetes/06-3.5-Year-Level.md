## 1. Troubleshooting Pod Failures (CrashLoopBackOff vs OOMKilled)
1. **CrashLoopBackOff:** Pod container starts, fails, exits, and K8s backs off restarting it.
   * Check: `kubectl logs <pod> --previous` to see why it crashed before restarting.
   * Check: `kubectl describe pod <pod>` for exit codes and configuration mismatches.
2. **OOMKilled (Exit Code 137):** Container exceeded its memory limit.
   * Diagnosis: In `kubectl describe pod`, inspect `Last State: Terminated` -> `Reason: OOMKilled`.
   * Solution: Increase `resources.limits.memory` or profile application memory leaks.
