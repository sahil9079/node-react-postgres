# Git & GitHub - Level 0: Beginner

## 1. What is Git & GitHub?
* **Git:** A distributed version control system running locally on your computer that tracks file changes over time.
* **GitHub:** A cloud-based hosting platform for Git repositories with collaboration features (Pull Requests, CI/CD, Issue tracking).

## 2. Real-World Analogy
Think of Git like a video game save system:
* **Working Directory:** Where you are actively playing the game.
* **Staging Area (`git add`):** Choosing which specific achievements you want to save.
* **Commit (`git commit`):** Creating a permanent checkpoint/save state with a timestamp and description.
* **Remote (`git push`):** Uploading your saved game to the cloud so your teammates can load and continue.
