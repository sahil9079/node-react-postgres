# AWS Fundamentals - Level 0: Beginner

## 1. What is AWS?
Amazon Web Services (AWS) is a cloud computing platform providing on-demand infrastructure resources (virtual servers, storage, databases, networking, and managed Kubernetes clusters) on a pay-as-you-go model.

## 2. Why do we need it?
* **Zero Hardware Management:** Eliminate physical datacenter procurement, power, and cooling overhead.
* **Global Availability:** Deploy infrastructure in multiple geographic regions and Availability Zones in minutes.
* **Elastic Scalability:** Automatically add or remove servers based on user demand.
