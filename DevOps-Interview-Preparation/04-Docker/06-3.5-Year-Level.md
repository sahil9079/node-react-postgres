# Docker Fundamentals - Level 5: 3–3.5 Year Engineer Mastery

## 1. Container Triage: Why Did the Container Exit?
1. Check Exit Code via `docker inspect <ID> --format '{{.State.ExitCode}}'`:
   * **Exit Code 0:** Clean shutdown (Entrypoint process finished its job and exited).
   * **Exit Code 1:** Application uncaught runtime error / exception.
   * **Exit Code 137:** Process received `SIGKILL` (Usually Linux Host **OOMKilled** the container for exceeding memory limits).
   * **Exit Code 139:** Segmentation Fault in native library (C/C++).
   * **Exit Code 143:** Process received `SIGTERM` (Graceful stop request from orchestrator).
