# Linux Fundamentals - Level 0: Beginner

## 1. What is Linux?
Linux is an open-source, Unix-like operating system that manages the computer's hardware and software resources. In cloud computing and DevOps, virtually all servers, containers, and Kubernetes nodes run on Linux.

## 2. Why do we need it?
* **Stability & Reliability:** Linux servers run continuously for years without requiring reboots.
* **Security & Multi-Tenancy:** Built-in multi-user isolation, file-level permissions, and security subsystems (SELinux/AppArmor).
* **Resource Efficiency:** Headless (no GUI) operation saves CPU and memory for running applications.
* **Scriptability & Automation:** Every system action can be automated via the command-line shell (Bash).

## 3. Real-World Analogy
Think of the Linux Operating System like an airport:
* **The Kernel** is Air Traffic Control (manages runways, planes, fuel, schedule).
* **The Hardware** is the physical airport runways, gates, and airplanes.
* **User Space Programs** are the passengers and airline staff using the airport services via standard tickets (System Calls).

## 4. Basic Terminology
* **Kernel:** The core program that interfaces between hardware and software.
* **Shell:** The command-line interpreter (e.g., Bash, Zsh) that allows users to send commands to the OS.
* **Terminal / CLI:** The text-based window used to interact with the shell.
* **Distribution (Distro):** A packaged version of Linux containing the kernel, package manager, and utilities (e.g., Ubuntu, Debian, RHEL, Amazon Linux).
* **Root User:** The superuser account with full administrative privileges over the entire system.
